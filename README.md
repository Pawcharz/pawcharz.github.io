# pawcharz.github.io

Personal website of Paweł Blicharz. Plain HTML, CSS and a little JavaScript, no build step.

- `index.html` is the whole page.
- `style.css` holds colours (light and dark follow the system), type and layout.
- `script.js` only fades the name into the top bar on scroll.
- `assets/` holds the photos, the Obelus demo video and project images.

Published with GitHub Pages from the `main` branch. To preview locally:

```
python -m http.server 8765
```
